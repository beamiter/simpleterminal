*simpleterminal.txt*  Local and remote popup terminals for Vim9

:SimpleTerminalNew [command]  Start a terminal for the active workspace.
:SimpleTerminalToggle         Show or hide the current terminal.
:SimpleTerminalNext           Switch to the next session.
:SimpleTerminalPrev           Switch to the previous session.
:SimpleTerminalKill           Stop and remove the current session.
:SimpleTerminalSend {text}    Send text followed by Enter.
:SimpleTerminalList           List sessions.
:SimpleTerminalHealth         Show integration health.

SimpleRemote integration is discovered through g:SimpleRemoteTerminalSpec().
